# Image sources

These are existing Where's Waldo? illustrations by Martin Handford, not generated artwork.

- `waldo-beach.jpg`: the beach edition containing Waldo, Odlaw, and Wizard Whitebeard, retrieved from https://whereiswaldo.com/assets/level1-scene.webp and converted to JPEG. The previous beach asset lacked the required supporting characters.
- `waldo-gluttons.jpg`: `original-images/5.jpg` from https://github.com/vc1492a/Hey-Waldo.
- `waldo-nasties.jpg`: retrieved from https://whereiswaldo.com/assets/level3-scene.webp and converted to JPEG.

Target locations were cross-checked against the reference game's locations and visually inspected in these exact image versions. Dataset labels include look-alikes and should not be used as exact target boxes.

The Hey Waldo repository's Open Database License covers its database; it does not by itself grant rights to the individual illustrations. The artwork remains subject to its creators' and publishers' rights. Listing these sources is attribution, not a claim that the illustrations are public domain.
